# 2026-11-14

## Code dump generator (`scripts/dump-code.mjs`, commit b53004b)
- The old `project-code-dump.txt` was produced by a `python bundle_code.py` that
  was never committed. Replaced it with a Node generator + `npm run dump`.
- Format preserved: header (revision/file/line/token counts), glance, tree of
  included files only, dotted TOC, then fenced per-file blocks with language tags.
- Auto-discovers sources; excludes `node_modules`, `dist`, `.git`, `target`, `gen`,
  `public`, `.tmp`, `shots`, `.workbuddy-ai`, binaries, `package-lock.json`, and the
  generated `src/data/exerciseCatalog.ts`. `project-code-dump.txt` stays gitignored.
- Windows gotcha: use `fileURLToPath(import.meta.url)` — `URL.pathname` yields
  `/C:/...` which `path.resolve` turns into `C:\C:\...`. Also `inExcludedDir` must
  split on `/` (rel is already normalised) or it silently walks into node_modules
  and `src-tauri/target` (first run produced 1453 files / 3.8 MB).

## v6 batch: water timer reset, muscle detection, native backup
- **Water timer**: `+۱ لیوان` now restarts a full interval. `nutrition.ts::setWaterGlasses`
  and `workout.ts::waterBar` call `startNewWaterReminderCycle(...)` only when
  `next > previous && waterReminderEnabled`; otherwise plain `persist(0)` (so the
  e2e clicks that happen before the toggle is enabled are unaffected).
  `notify.ts` got `bumpWaterDeadlineOnDrink()` (deadline math duplicated locally to
  avoid a `timer.ts ↔ notify.ts` import cycle) used by `addWaterGlass`, and
  `__onSilentWaterIncrement` mirrors the receiver's new deadline into memory.
- **Native receiver** (`scripts/setup-android-native.mjs`): `ACTION_DRINK_ONE` now
  calls `rescheduleFromState(context)`; Toast uses Persian digits. `stateFile()`
  checks BOTH `context.dataDir` and `context.filesDir` and prefers whichever
  exists — the pasted code claimed filesDir is the Tauri standard, but this repo's
  verified note says `app_data_dir()` = `activity.dataDir`. Checking both is safe
  because both callers bail out when no file exists.
- **Muscle detection**: replaced the word-overlap scorer in `workoutTools.ts` with
  exact catalog match (GIF/name/English query) → ordered compound phrase table
  (`MUSCLE_KEYWORDS`) → `EXERCISE_MUSCLE_MAP` for d1e1..d4e6 → overlap fallback
  that KEEPS 2-letter words. The old `word.length > 2` filter dropped «پا», so
  «جلو پا» matched the ten «جلو بازو» rows. Modal gained muscle filter chips
  (`aria-label="فیلتر <label>"`) with `paintList()` re-render.
- **Double toast**: `swapBusyExercise` now restores an existing swap silently in
  memory (no `restoreOriginalExercise()` call from the picker), so one toast.
- **Deload**: snapshot moved from an in-memory `Map` to
  `localStorage["persian-hypertrophy::deload-snapshot"]`, keyed `${day.id}:${id}`
  (bare id still read for legacy), cleared on exit.
- **`.gif` bug**: `workout.ts` `fallbackUrl` was `/gifs/<id>.svg` but only `.gif`
  files exist in `public/gifs/`.
- **Native Android backup** (3rd pasted quote was TRUNCATED mid-file, so the
  missing two files were reconstructed): added `BackupFileProvider`
  (ContentProvider, authority `<pkg>.backup`, cache/shared_backups) + two
  `@JavascriptInterface` methods to `AndroidWaterBridge`:
  `saveBackupToDownloads` via `MediaStore.Downloads` (Q+) with a pre-Q fallback,

  Manifest gets `<provider android:exported="false" grantUriPermissions="true">`.
  JS helpers `nativeSaveBackupToDownloads` / `nativeShareBackupFile` /
  `hasNativeBackupBridge` live in `src/lib/api.ts`; `progressPhotos.ts` share no
