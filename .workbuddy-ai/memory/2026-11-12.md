## APK size (499 MB → 36 MB)

- Cause: universal debug APK packed 4 ABIs (arm64-v8a, armeabi-v7a, x86, x86_64), each with `libpersian_hypertrophy_lib.so` built with `[profile.dev]` = full DWARF (~120 MB each). The Tauri debug build type also sets `jniLibs.keepDebugSymbols` for every ABI, so symbols land inside the APK. Frontend assets are only ~110 KB.
- Fix (CI only): default `target: aarch64` + `CARGO_PROFILE_DEV_STRIP=debuginfo` env on the build step (Cargo env override, leaves local `[profile.dev]` untouched).
- Result: run 43117241863 → 35.8 MB artifact, 3 min build (was 499 MB / 9 min). `target: all` still builds the universal APK.
