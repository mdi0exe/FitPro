## v5 batch (commit 4bd9f4d, CI run 43499714319 green) — keystore, SVG UI, auto week parity, AI diet, exercise history
- **Root cause of the recurring "uninstall wipes my data"**: every fresh CI runner generates
  its own `~/.android/debug.keystore`, so each APK carried a *different* certificate →
  `INSTALL_FAILED_UPDATE_INCOMPATIBLE` → forced uninstall → `gym_state.json` gone.
  Fix: `scripts/ensure-keystore.mjs` (`npm run keystore`) generates a committed
  `src-tauri/keystore/debug.keystore` with `keytool -genkeypair -storetype PKCS12`
  (stated explicitly so JDK 9+/older agree), storepass/keypass `android`, alias
  `androiddebugkey`, RSA 2048, validity 10000, `CN=Android Debug,O=Android,C=US`.
  CI step "Install persistent debug keystore for seamless APK updates" copies it to
  `$HOME/.android/debug.keystore` **before** `Build debug APK` and asserts the alias with
  `keytool -list | grep -q androiddebugkey`. Committed cert SHA256
  `51:32:F5:07:8B:EA:A4:89:5F:75:B2:2C:96:E5:DB:86:E7:FD:7A:41:FD:E0:CE:64:8F:40:5B:60:AD:75:D7:99`,
  valid to 2054-03-31. `src-tauri/gen/android` stays git-ignored, so everything else
  must remain an idempotent script.
- Emoji purge: default name `"دانشجوی ورزشکار"` → `"کاربر"` (`models.rs`, `seed.ts`,
  `onboarding.ts`); header subtitle uses real `icons.graduation` / `icons.dumbbell`;
  new icons `sun`, `moon`, `share`, `cpu`, `graduation`, `copy`, `download`.
  `.btn-icon` was squashed because flex-column children default to `flex-shrink:1` →
  `h-10 w-10 shrink-0 p-0 leading-none` + `.btn-icon > svg { display:block; margin:auto; flex:none }`.
  Cheesy copy replaced (`استراحت تمام شد. ست بعدی را آغاز کنید.`, `عملکرد امروز ثبت شد`, …).
- Auto odd/even weeks: `semesterWeekAnchorDate` in state; `semesterWeekNumber()` /
  `effectiveSemesterWeekType()` derive parity from `floor(daysBetween(anchor, thisSat)/7)`
  (symmetric via `Math.abs` so dates before the anchor still work). The manual switch is
  gone — a status strip `هفته N ترم • یک‌ستاره/دوستاره` + an anchor modal (`هفته بعد` /
  `هفته قبل`) replaces it. Hidden entirely when no course is `odd`/`even`.
- Scoped sharing (`src/lib/uniShare.ts`): `courses` and `shuttle` payloads are separate,
  so importing classes can never clobber `customShuttleJson`. `src/lib/clipboard.ts`
  adds the hidden-textarea `execCommand("copy")` fallback (Android WebView often denies
  `navigator.clipboard`).
- `src/components/aiDietConfigurator.ts`: builds a Persian prompt with the real profile
  numbers + a strict JSON skeleton (`calories/protein/trainingWindow/meals/checklist/coachRules`),
  parses the answer back (tolerates ```json fences), clamps values, and **re-appends the
  mandatory `diet-4` water row** after rebuilding `state.diet.items`. Coach tab renders the
  AI rules and its intro count is dynamic (was hard-coded "۳ قانون طلایی").
- `scripts/build-exercise-library.mjs` now emits `equipmentKey` / `movement` / `tip` per
  movement (`generateExerciseTipFa` composes movement + muscle + equipment cues, kept
  equipment-neutral so swaps stay honest). `openSwapExerciseModal` lists all same-muscle
  catalog rows with GIF + tip + a "return to original" option.
- `src/components/exerciseHistory.ts`: `exerciseHistory: HashMap<String, Vec<Entry>>`,
  folded per-day from the **top** completed set, capped at 120/movement, sparkline only
  when `entries.length >= 2` (a one-point chart is undrawable → explanatory box instead).
  `src/components/doubleProgression.ts`: +2.5 kg with reps reset to the range floor,
